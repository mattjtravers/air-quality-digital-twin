# Dashboard — EARS Specs

Facets: `WIN` (the window and the latest hour), `IN` (what the build reads), `GAP` (hour status),
`FRAME` (reprojection, colouring, encoding), `MAN` (the manifest), `SITE` (the output directory
and the build summary), `WEB` (the front end), `TEST` (how this segment is tested).

## Window

- [x] **DASH-WIN-001**: The dashboard shall expose `build_site(archive_uri, out, *, hours=48, end=None, generated_at, map_settings=None) -> BuildSummary`, requiring a timezone-aware `generated_at` and a positive `hours`, and shall not read the clock.
- [x] **DASH-WIN-002**: When `build_site` is called without `end`, the dashboard shall take as the latest hour the latest hour whose `surface_fits` row has status `kriged`, among rows for hours before `generated_at` in the `surface_fits` partitions of the seven days up to `generated_at`. The window shall be the `hours` consecutive hours ending with the latest hour, inclusive.
- [x] **DASH-WIN-003**: When `build_site` is called with `end`, the dashboard shall convert `end` to UTC, truncate it to the hour, take the window `[end − hours, end)`, and take as the latest hour the latest hour in that window whose `surface_fits` row has status `kriged`.
- [x] **DASH-WIN-004**: If no hour in the search span (DASH-WIN-002) or the window (DASH-WIN-003) is kriged, then the dashboard shall raise an error naming the span searched, before writing anything to `out`.

## Inputs

- [x] **DASH-IN-001**: The dashboard build shall read `surface_fits`, the surface rasters those rows name, AirNow observations, site records, and `calibrated_hourly` from the archive through the observation store's primitives and Maps' `read_surface`, restricted to the window's dates, and shall rebuild each kriged hour's kriging points from `calibrated_hourly` and the site records with fusion's `hour_points`. It shall open no PostGIS connection and issue no request to any source API.

## Hour Status

- [x] **DASH-GAP-001**: The dashboard shall give every hour in the window exactly one status: `kriged` when its fit row says `kriged` and its raster was read; `insufficient_points` or `fit_failed` when its fit row says so; `missing` when it has no fit row; and `surface_missing` when its fit row says `kriged` but its raster cannot be read.
- [x] **DASH-GAP-002**: When an hour's status is `surface_missing`, the dashboard shall log a warning naming the hour and the raster URI and continue the build.
- [x] **DASH-GAP-003**: When an hour's status is not `kriged`, the dashboard shall write no frames for it, and its manifest entry shall carry null `pm25_png`, `diff_png`, `sd_png`, `bounds_latlon`, `surface_min`, `surface_mean`, `surface_max`, `sd_max`, `variogram_model`, `range_km`, `nugget`, `sill`, `nugget_share`, and `monitor_mean_difference`, `monitor_n` 0, and null `map_value` and `difference` on every monitor.

## Frames

- [x] **DASH-FRAME-001**: For each `kriged` hour, the dashboard shall reproject three arrays from EPSG:26918 to EPSG:3857 with `rasterio.warp.reproject` and nearest-neighbour resampling: band 1; band 1 minus the mean of band 1's finite cells (the unrounded `surface_mean`); and the square root of band 2 (each variance clamped at 0 first). The destination transform and size shall come from `calculate_default_transform` for the grid's bounds, and destination cells outside the source grid shall be NaN.
- [x] **DASH-FRAME-002**: The dashboard shall take each frame's RGB from Maps' `colorize` of the reprojected estimate (`kind="pm25"`), difference (`kind="diff"`), and standard deviation (`kind="sd"`), using the build's `MapSettings`, and shall add no axes, colorbar, title, or marker to a frame.
- [x] **DASH-FRAME-003**: The dashboard shall encode each frame as an RGBA PNG carrying no text, time, or other metadata chunks, so that identical arrays produce identical bytes, and shall write it to `data/frames/{kind}_{YYYY-MM-DDTHH}.png` for `kind` in `pm25`, `diff`, `sd` and the hour's start in UTC.
- [x] **DASH-FRAME-004**: For each `kriged` hour, the dashboard shall set `bounds_latlon` to the frame's EPSG:3857 extent with its south-west and north-east corners converted to WGS84, written `[[south, west], [north, east]]`.
- [x] **DASH-FRAME-005**: For each `kriged` hour, the dashboard shall compute `surface_min`, `surface_mean`, and `surface_max` over band 1's finite cells, and `sd_max` over the standard-deviation array's finite cells, all on the source grid before reprojection.
- [x] **DASH-FRAME-006**: For each `kriged` hour, the dashboard shall set `nugget_share` to the hour's fit-row `nugget` divided by its `sill`, rounded to two decimal places, and to null when the sill is 0 or either value is missing.
- [x] **DASH-FRAME-007**: For each `kriged` hour, the dashboard shall build an alpha array on the source grid, `α = 0.85 − 0.25 · min(sd / √sill, 1)` with `sill` the fit row's (0.85 everywhere when the sill is 0 or missing), set to 0.40 at every cell whose centre lies farther than `max(range_m, 5000)` metres, `range_m` the fit row's, from the nearest of the hour's rebuilt kriging points (no cell when there are none), reproject it as DASH-FRAME-001 reprojects the frames, and set the alpha of each of the hour's three frames to `round(255 · α)` at finite cells and 0 at NaN cells.
- [x] **DASH-FRAME-008**: For each `kriged` hour, the dashboard shall set `range_km` to the fit row's `range_m` divided by 1000, and `nugget` and `sill` to the fit row's values.

## Manifest

- [x] **DASH-MAN-001**: The dashboard shall write `data/manifest.json` validated by the Pydantic model `Manifest`, carrying `generated_at`, `latest_hour`, `window_start`, `window_end` (exclusive), `scales`, and `hours`, with every timestamp an ISO 8601 UTC string.
- [x] **DASH-MAN-002**: The manifest's `hours` shall hold one entry per hour of the window, ascending and contiguous, each carrying `hour`, `status`, `pm25_png`, `diff_png`, `sd_png`, `bounds_latlon`, `surface_min`, `surface_mean`, `surface_max`, `sd_max`, `n_sensors`, `variogram_model`, `range_km`, `nugget`, `sill`, `nugget_share`, `monitor_n`, `monitor_mean_difference`, `monitors`, and `sensors`. `n_sensors` and `variogram_model` shall come from the hour's fit row (`n_sensors` null when it has none), and the frame paths shall be relative to the site root.
- [x] **DASH-MAN-003**: The manifest's `scales` shall carry, for each of `pm25`, `diff`, and `sd`, the limits `min` and `max` and the colormap name `cmap` from Maps' `scale`, `units` `µg/m³`, the colorbar `label` Maps uses for the kind, and `stops`: eleven colours evenly spaced from `min` to `max`, as `#rrggbb` strings from Maps' `colour_stops`.
- [x] **DASH-MAN-004**: Each hour's `monitors` shall be the AirNow observations whose `observed_at` equals the hour, joined to their site records, each with `site_id`, `name`, `lat`, `lon`, `obs` (the observation's `pm25_raw`, null when absent), `qc_flags` (its flag list), `map_value`, and `difference`. This holds for every hour, whatever its status.
- [x] **DASH-MAN-005**: Each hour's `sensors` shall be every `calibrated_hourly` row for the hour whose `site_id` has a site record, each with `sensor_id` (the `site_id`), `lat`, `lon`, `pm25_calibrated` (null for an `uncalibrated` row), and `fit_status`. This holds for every hour, whatever its status.
- [x] **DASH-MAN-006**: The dashboard shall round coordinates in the manifest to five decimal places, `nugget` and `sill` to four, and every other float to two, sort `monitors` by `site_id` and `sensors` by `sensor_id`, and write the JSON with sorted keys, so that two builds over the same archive state with the same arguments differ only in `generated_at`.
- [x] **DASH-MAN-007**: For each `kriged` hour, the dashboard shall set each monitor's `map_value` to band 1 of the raster cell containing the monitor's EPSG:26918 coordinates, found with evaluation's `cell_index`, null when the monitor lies outside the grid or the cell is NaN; its `difference` to `map_value − obs`, null when `qc_flags` is non-empty or either value is null; the hour's `monitor_n` to the number of its monitors with a non-null `difference`; and `monitor_mean_difference` to the mean of those differences before rounding, null when `monitor_n` is 0.

## Site Output

- [x] **DASH-SITE-001**: The dashboard shall assemble the site in a new temporary directory beside `out` and move it into place only after every file is written, so that a build that raises leaves `out` unchanged.
- [x] **DASH-SITE-002**: If `out` exists, is not empty, and holds no `data/manifest.json`, then the dashboard shall raise an error naming `out` without modifying it.
- [x] **DASH-SITE-003**: The dashboard shall copy every file under `src/aqdt/dashboard/web/` (`index.html`, `app.js`, `style.css`) to the root of the site.
- [x] **DASH-SITE-004**: `BuildSummary` shall carry `window_start`, `window_end`, `latest_hour`, the count of hours by status, the number of frames written, the site's total size in bytes, and the elapsed seconds.
- [x] **DASH-SITE-005**: When a build's elapsed time exceeds 300 seconds or its site exceeds 50 MB (50 × 10⁶ bytes), the dashboard shall log a warning naming the target exceeded and the measured value.

## Front End

- [x] **DASH-WEB-001**: The front end shall be static HTML, CSS, and JavaScript with no build step. It shall load Leaflet 1.9.4 from cdnjs with Subresource Integrity hashes on both the script and the stylesheet, and draw OpenStreetMap standard tiles with OpenStreetMap's attribution and Esri's World Boundaries and Places reference tiles with Esri's attribution.
- [x] **DASH-WEB-002**: When the page loads, the front end shall fetch `data/manifest.json` bypassing the browser's HTTP cache, fit the map to the frames' `bounds_latlon`, and show the latest hour's frame as one image overlay at opacity 1, the frame carrying its own alpha.
- [x] **DASH-WEB-003**: The front end shall provide a toggle of three buttons carrying `aria-pressed`, labelled and ordered Estimate, Difference, Uncertainty, switching the overlay between each hour's `pm25_png`, `diff_png`, and `sd_png`.
- [x] **DASH-WEB-004**: The front end shall draw a legend for the active kind as a gradient through that scale's `stops`, labelled with its `min`, its `max`, its `units`, and its `label`. When the current hour's values pass the scale's `max` it shall show ▲ at the legend's upper end, and when they pass its `min` ▼ at the lower end, each with the text "values beyond the scale shown in its end colours". The current hour's values run from `surface_min` to `surface_max` (Estimate), from `surface_min − surface_mean` to `surface_max − surface_mean` (Difference), and up to `sd_max` (Uncertainty). When the hour shown is `kriged`, the legend shall show "Faded areas: far from sensors / high uncertainty".
- [x] **DASH-WEB-005**: The front end shall provide a play/pause button and a range slider spanning every hour of the manifest, gap hours included. Playback shall advance one hour per 500 ms and loop to the first hour after the last.
- [x] **DASH-WEB-006**: The front end shall label the hour shown in Eastern time only, computed with `Intl.DateTimeFormat` in `America/New_York`, as the Eastern date of the hour's start followed by the hour's span on a 12-hour clock with the zone's abbreviation (`Fri, Nov 6 · 2:00 PM–3:00 PM EST`). When the start and end of the hour carry different zone abbreviations, each end shall carry its own (`1:00 AM EDT–1:00 AM EST`).
- [x] **DASH-WEB-007**: The front end shall preload the frames of every kriged hour before playback starts.
- [x] **DASH-WEB-008**: When the hour shown is not `kriged`, the front end shall draw no overlay and show "No surface:" followed by a plain-language reason for the hour's status.
- [x] **DASH-WEB-009**: The front end shall draw the shown hour's AirNow monitors as hollow triangles with no fill, labelled with `obs` to one decimal place followed by `*` when `qc_flags` is non-empty (or `n/a` when `obs` is null), then ` · map {map_value}` when `map_value` is non-null, then ` ({difference})` when `difference` is non-null, each to one decimal place with negative values signed `−` and positive `difference` signed `+`.
- [x] **DASH-WEB-010**: The front end shall draw the shown hour's PurpleAir sensors as small hollow circles with no fill. Activating one shall open a popup with its `sensor_id`, its calibrated value with units (or "no calibrated value"), and its `fit_status`.
- [x] **DASH-WEB-011**: The front end shall show `Latest hour h:mm AM|PM {zone}, updated h:mm AM|PM {zone}` from `latest_hour` and `generated_at` in Eastern time, formatted as DASH-WEB-006 formats the hour label's times.
- [x] **DASH-WEB-013**: The front end shall provide a collapsible About panel stating the data sources (PurpleAir sensors with the EPA US-wide correction of Barkjohn et al. 2021, calibrated against AirNow monitors, kriged hourly), what the difference map shows, what the uncertainty map shows (the kriging standard deviation: how far the estimate could be from the true value, from the interpolation alone), that independent testing (Oct 26 – Nov 15, 2026) found the full uncertainty, which also includes the calibration and an hour-wide shared error, about twice as large as the kriging standard deviation and a typical 95% range of about ±4 µg/m³ around the map value, that the nugget share is the part of sensor-to-sensor variation the variogram treats as short-scale noise or measurement error (typical for low-cost sensors) and that a high share means the map smooths toward the hour's average, that faded areas are far from sensors or highly uncertain, what the monitor labels show and that selecting a monitor shows its history over the window, that AirNow data are preliminary, and that the page is not for regulatory or health decisions, with a link to the repository.
- [x] **DASH-WEB-014**: Every control outside the map shall be a native button or range input operable from the keyboard with a visible focus indicator and an accessible name. The overlay image shall carry alt text naming the kind and hour shown, updated with each frame. At a viewport 360 px wide the page shall lay out in one column with no horizontal scrolling.
- [x] **DASH-WEB-015**: When the hour shown is `kriged`, the front end shall caption it `Kriged from N sensors · {variogram_model} variogram · values {surface_min}–{surface_max} µg/m³ · variogram range {range_km} km · nugget {P}% of sill`, with the values and the range to one decimal place and `P` the `nugget_share` as a whole percentage, omitting the variogram-range part when `range_km` is null and the nugget part when `nugget_share` is null.
- [x] **DASH-WEB-016**: Whenever the hour shown or the map's zoom changes, the front end shall place the shown hour's AirNow monitor labels one at a time in the order of the hour's `monitors`, each on the first side of its triangle — right, left, below, above — where the label's box overlaps no label already placed and no other monitor's triangle, or on the right when no side is clear. PurpleAir sensor markers and the map's edges shall not constrain the placement.
- [x] **DASH-WEB-017**: The front end shall draw the Esri World Boundaries and Places tiles (DASH-WEB-001) in a map pane above the surface overlay and below the AirNow monitor and PurpleAir sensor markers, and that pane shall take no pointer events.
- [x] **DASH-WEB-018**: When the hour shown is `kriged` and its `monitor_n` is at least 1, the front end shall show under the caption `Monitors: mean difference {monitor_mean_difference} µg/m³, n = {monitor_n}`, the difference to one decimal place signed as DASH-WEB-009 signs a difference, and shall show nothing there otherwise.
- [x] **DASH-WEB-019**: When the hour shown is `kriged` and its `range_km` is below 1, the front end shall show on the map the note "Spatial pattern not detectable this hour; map ≈ hour average.", and shall hide it on every other hour.
- [x] **DASH-WEB-020**: When the reader clicks, taps, or activates from the keyboard an AirNow monitor's triangle, the front end shall open a popup headed with the monitor's `name` (its `site_id` when `name` is null), holding the monitor's history chart (DASH-WEB-021) and window statistics (DASH-WEB-022), drawn from the manifest's `monitors` entries with that `site_id` across every entry of `hours`.
- [x] **DASH-WEB-021**: The monitor history chart shall be inline SVG drawn without a charting library, its x axis spanning every hour of the manifest in order (gap hours included) and labelled with the first and last hours' Eastern dates, its y axis running from 0 to the largest `obs` or `map_value` plotted, with tick labels `0` and that maximum to one decimal place and the axis label `µg/m³`. It shall draw each hour's `obs` as a dot, filled when `qc_flags` is empty and hollow otherwise, with no dot where `obs` is null or the hour lists no such monitor; the `map_value` as a line joining consecutive hours, broken wherever `map_value` is null or the hour lists no such monitor; a vertical marker at the hour shown; and a two-entry legend reading "● observed" and "— map".
- [x] **DASH-WEB-022**: Below the monitor history chart, the front end shall show `Last {N} h: mean difference (map − observed) {D} µg/m³ · RMSE {R} µg/m³ · n = {n}`, with `N` the number of entries in the manifest's `hours`, over the monitor's hours whose `difference` is non-null, with `D` their mean signed as DASH-WEB-009 signs a difference, `R` the square root of the mean of their squares to one decimal place, and `n` their count. When no hour has a non-null `difference`, it shall show `Window: no hours with a map–monitor difference`.
- [x] **DASH-WEB-023**: While a monitor history popup is open and the hour shown changes, the front end shall keep the popup open, move its hour marker to the hour shown, and leave its chart and statistics otherwise unchanged. The popup shall close from its close button, on Escape, or when another popup opens.
- [x] **DASH-WEB-024**: Each AirNow monitor's triangle shall be in the keyboard tab order with role `button` and the accessible name `AirNow monitor {name}`, and Enter or Space on it shall open its popup. When a monitor history popup closes on Escape, focus shall return to the triangle that opened it. The history chart shall carry `role="img"` and an accessible name stating the monitor's name, that it plots observed and map PM2.5 over the window, and the DASH-WEB-022 statistics text. At a viewport 360 px wide the open popup shall lie wholly within the viewport.
- [x] **DASH-WEB-025**: While the Uncertainty view is active, the front end shall show in the legend, on every hour, "Shading shows kriging uncertainty only. In testing, the full 95% range was about ±4 µg/m³ (see About).", and shall hide it in the Estimate and Difference views.

## Testing

- [x] **DASH-TEST-001**: Dashboard tests shall build sites from a fixture archive in a temporary directory, containing at least a kriged hour, a non-kriged hour, and an hour with no fit row. They shall require no network, no AWS credentials, and no database, apart from DASH-TEST-002.
- [x] **DASH-TEST-002**: A smoke test shall build the site from the fixture archive, serve it over local HTTP, and load `index.html` in Playwright's Chromium. It shall assert that the frames load, that moving the slider changes the hour label and the overlay image, and that the toggle switches the overlay to the `sd` frame. It shall answer OpenStreetMap and Esri tile requests locally with a blank tile, and shall skip when Playwright or its Chromium is not installed.
- [x] **DASH-TEST-003**: The devcontainer's post-create script shall install Playwright's Chromium together with its system libraries (`playwright install --with-deps chromium`), after `uv sync --all-groups`, so that DASH-TEST-002 runs in a fresh Codespace. If the install fails, the script shall report it and continue, without failing the Codespace's creation.
