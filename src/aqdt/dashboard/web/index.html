About this map

The estimate is hourly PM2.5 (fine particulate matter, µg/m³) across the Washington, D.C. metro. It is built from PurpleAir low-cost sensors, corrected with the EPA US-wide PurpleAir correction (Barkjohn et al. 2021) and calibrated against nearby EPA AirNow reference monitors. The calibrated sensor values are then interpolated by ordinary kriging, refitted every hour.

The uncertainty map shows the kriging standard deviation in µg/m³: how far the estimate could plausibly be from the true value. It is lowest close to sensors and grows with distance from them. Read the two maps together: where the uncertainty map is bright, the estimate there is less certain.

Triangles mark AirNow reference monitors with their observed value for the hour. They are not used to build the surface, so they are an independent check on it. AirNow data are preliminary and unvalidated, and may be revised.

This is a research prototype, not for regulatory or health decisions. For official air quality, see AirNow.gov.

Source code and documentation: https://github.com/mattjtravers/air-quality-digital-twin.
